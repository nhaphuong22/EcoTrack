# EcoTrack paper kit

- `ieee/`: IEEE Conference source.
- `springer/`: Springer LNCS source.
- `architecture/ecotrack-system-architecture.svg`: editable 1600×900 vector diagram.

Before uploading to Overleaf, export the SVG as `ecotrack-system-architecture.pdf` and keep it in the `architecture/` folder. Choose one publication template as the project root.
